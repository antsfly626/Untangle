# Untangle frontend

Next.js App Router with TypeScript, Tailwind CSS, and React Flow.
Requires Node.js 20.9 or newer and npm.

Run commands from `Untangle/frontend`; this directory owns the frontend
package manifest and lockfile.

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

## Validation and production

```bash
npm run lint       # ESLint
npm run typecheck  # Generate route types and check TypeScript
npm run build     # Create a production build
npm start         # Serve the production build
```

System fonts keep builds independent of Google Fonts downloads.

## Implementation conventions

- `src/app/page.tsx`: home page placeholder.
- `src/app/layout.tsx`: shared document layout and metadata.
- `src/app/globals.css`: Tailwind import and global theme tokens.
- Use `@/` imports for files under `src/`.
- Add shared UI to `src/components/` and API helpers to `src/lib/` as needed.
- Keep pages and layouts as Server Components by default. Use `"use client"`
  for interactive components, including React Flow canvases; import
  `@xyflow/react/dist/style.css` when adding the first canvas.
- Add `public/` when static assets are needed.
- Store local configuration in `.env.local`. Only `NEXT_PUBLIC_` variables
  belong in browser code; keep API keys and secrets on the server.
- `.next/`, `node_modules/`, and `next-env.d.ts` are generated files. Route
  types and `next-env.d.ts` are regenerated by `npm run typecheck`.
